# herdr-themes

My [Herdr](https://herdr.dev) layouts and themes. One folder per layout.

| Layout | What it is |
| --- | --- |
| [`amber/`](amber) | Warm amber-on-brown look, BlexMono Nerd Font Mono (Nerd Font build of IBM Plex Mono), rounded pane cards |

## Install

Ask your Herdr agent to add `https://github.com/sandornaut/herdr-themes/tree/main/amber`,
or copy by hand: `layouts/*.json` → `~/.config/herdr-app/layouts/`, `themes/*.json` →
`themes/`, `mods/*` → `mods/`. Then `herdr-app check` and switch layouts with `ctrl-shift-l`.

Install the Nerd Font first for the intended look: `brew install --cask font-blex-mono-nerd-font`.
