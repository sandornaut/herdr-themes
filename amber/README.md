# amber

Layout, theme and eight mods (`amber-*`). Uses BlexMono Nerd Font Mono, the Nerd Fonts build of IBM Plex Mono. The font files are bundled in `mods/amber-workspace-chrome/fonts/` (SIL OFL 1.1, license included), so Herdr loads them itself and nothing needs installing.

Heads-up: `amber-changes`, `amber-files` and `amber-spaces` run programs via `exec`
(git, sh) and read files; `amber-spaces` also uses `hc`. None use the network.

`RECIPE.md` and `preview.png` are included. The preview is an illustration with made-up data (source: `assets/preview-source.svg`), not a screenshot.
